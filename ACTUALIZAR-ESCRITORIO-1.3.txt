MI CV ESCRITORIO 1.3 — FORMULARIOS Y REPORTES

ACTUALIZAR EN WINDOWS
1. Cierre Mi CV. Haga un respaldo desde Cuenta y respaldo.
2. Extraiga este ZIP con el Explorador de Windows.
3. Copie la carpeta desktop sobre C:\Users\CPUw0126\micv\desktop, reemplazando los archivos del código.
4. Abra PowerShell dentro de desktop y ejecute:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Compilar-Windows.ps1
   Para crear solamente el portable agregue: -PortableOnly
5. Instale el nuevo instalador, o abra dist\MiCVDesktop\MiCVDesktop.exe.
   Para mover el portable copie TODA la carpeta MiCVDesktop.

Este paquete contiene código fuente actualizado; no incluye un EXE compilado.
La compilación instala las dependencias nuevas automáticamente.
No borre %LOCALAPPDATA%\EquipoJZ\MiCVDesktop: contiene cuentas y datos locales.
Si ya se conecta con la versión 1.2, NO necesita actualizar Laravel,
ejecutar migraciones ni generar otra firma para esta versión.

CAMBIOS
- Formularios con desplazamiento interno y Guardar/Cancelar siempre visibles.
- Ficha del cliente organizada en tres secciones.
- Si hay un error al guardar, conserva lo escrito y muestra el error.
- Interfaz compacta para pantallas pequeñas; módulos disponibles en el menú superior.
- PDF y Excel de clientes, productos, contabilidad, sincronización y ventas del equipo.
- PDF vertical, horizontal o automático, texto nítido, tablas y páginas numeradas.
- Excel con filtros, encabezados fijos y cantidades numéricas; conserva ceros de documentos.
- Logo para reportes configurable por cuenta desde Cuenta y respaldo.
  El logo se guarda en este equipo; puede volver a seleccionarlo tras restaurar un respaldo.
- Historial de ventas locales para recuperar comprobantes anteriores.
- Se mantienen cuentas separadas y licencia solo para empresas/empleados.

ALCANCE
Los reportes usan los datos locales disponibles en el equipo.
Las operaciones pendientes todavía deben ser aceptadas por Laravel al sincronizar.
CV, tarjetas, chat y administración general continúan en el sistema web.
Esta versión mejora los módulos locales existentes; no replica todavía toda la web sin internet.

VALIDACIÓN
27 pruebas de escritorio; revisión de formularios a 640x380 y POS a 900x520,
PDF de varias páginas, orientación vertical/horizontal y tipos de datos en Excel.
El instalador Windows debe compilarse y comprobarse en su PC.
